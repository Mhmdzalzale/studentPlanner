# Student Planner

A web application project I am building to learn modern web development from the ground up.

## About

This project started as a simple authentication system and will gradually evolve into a full student planner / productivity web app.

Planned features include:

* User signup
* User login
* Task management
* Assignment tracking
* Course organization
* Dashboard UI
* Data persistence
* Backend API integration
* Database integration

## Tech Stack

Current:

* HTML
* CSS
* JavaScript
* Browser Local Storage

Planned:

* React
* Node.js
* Express
* PostgreSQL

## Purpose

The goal of this project is to:

* Learn JavaScript deeply
* Understand frontend development
* Build backend APIs
* Work with databases
* Practice clean software engineering habits
* Use AI as a learning tool, not as a shortcut

## Current Progress

* Login page UI
* Signup page UI
* Password validation
* Duplicate user checking
* Local Storage user persistence
* Basic authentication flow
